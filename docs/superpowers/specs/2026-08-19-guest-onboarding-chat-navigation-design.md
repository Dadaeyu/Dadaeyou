# Guest Onboarding and Chat Navigation Design

## Goal

비로그인 사용자가 서비스를 막힘없이 둘러볼 수 있게 유지하면서 로그인·회원가입의 이점을 한 번 안내하고, 챗봇이 실제 서비스에 등록된 장소와 공개 코스를 앱 내부 화면으로 자연스럽게 연결한다.

## Product Requirements

- 로그인 유도는 강제가 아니다. `로그인 없이 둘러보기`를 명확한 동등 선택지로 제공한다.
- 인증 상태를 확인한 뒤 비로그인 사용자가 홈에 새로 진입할 때마다 한 번 안내한다.
- 홈 공지와 동시에 겹쳐 뜨지 않는다.
- 로그인, 회원가입, 공개 법률 페이지에서는 유도 안내를 표시하지 않는다.
- 챗봇은 새 코스를 생성하거나 존재하지 않는 코스를 만들어 말하지 않는다.
- 장소 카드는 다대유 내부 `/map` 화면에서 해당 장소를 선택한 상태로 연다.
- 코스 카드는 현재 DB의 공개 코스만 사용하고 내부 `/course/{id}` 상세로 이동한다.
- 코스 추천은 챗봇이 추천한 장소를 포함한 공개 코스를 우선하고, 그런 코스가 없지만 사용자가 코스를 요청했다면 후기 평점이 높은 공개 코스를 보여준다.
- 외부 네이버지도 링크는 사용하지 않는다.
- 홈 장소 상세와 인기 장소 카드도 정확한 `contentId`를 내부 지도에 전달한다. 지도는 해당 마커를 선택하고 상세를 연 뒤 확대·중앙 정렬한다.

## Guest Prompt UX

모바일에서는 하단 시트, 데스크톱에서는 중앙 다이얼로그로 보인다. 제목은 `여행을 저장하고 이어서 보세요`, 설명은 로그인 시 가능한 저장·즐겨찾기·코스 관리 이점을 짧게 전달한다. 기본 CTA는 로그인, 보조 CTA는 회원가입이며, `로그인 없이 둘러보기`는 현재 홈 진입 동안 안내를 닫는 명확한 버튼이다. 다른 화면을 둘러본 뒤 홈으로 돌아오면 다시 안내한다.

기존 디자인 시스템의 흰색 표면, navy/brand 강조색, hairline 테두리, 48px 이상의 터치 영역을 사용한다. 별도 시각 체계를 추가하지 않는다.

## Chat Integration UX

장소 카드의 `지도에서 위치 확인`은 `다대유 지도에서 보기`로 바꾸고 내부 라우팅을 사용한다. 정확한 `contentId`가 있으면 `/map?contentId=...&query=...&mode=map`, 없으면 `/map?query=...&mode=map`으로 이동한다. 이동 직전에 챗봇을 닫아 지도를 즉시 볼 수 있게 한다.

장소 추천 아래에는 연관된 기존 공개 코스가 있을 때 `이 장소가 포함된 코스` 영역을 보여준다. 코스 카드는 첫 장소 사진, 코스명, 포함 장소 요약, 평점·후기·즐겨찾기 수, 해시태그를 표시한다. 사용자가 `코스`를 직접 요청했는데 연관 코스가 없으면 평점 순 공개 코스를 최대 3개 보여준다.

## Data Flow

1. 챗 API가 관광 지식 행의 `metadata.contentid`를 장소 카드의 `contentId`로 전달한다.
2. 클라이언트는 장소 `contentId` 목록으로 `/api/courses/shared?contentIds=...&sort=rating_desc&limit=3`을 조회한다.
3. 공개 코스 API는 기존 `courseIdsContainingContentIds` 로직을 재사용해 해당 장소가 하나라도 포함된 코스만 반환한다.
4. 결과가 없고 질문이 코스 요청인 경우 `/api/courses/shared?sort=rating_desc&limit=3`을 한 번 조회한다.
5. 채팅 메시지에 받은 공개 코스 객체를 저장해 동일 세션 복원에도 카드가 유지되게 한다.

## Accessibility and Failure Handling

- 모든 주요 버튼은 최소 높이 48px, 명확한 focus 상태와 한국어 접근성 이름을 가진다.
- 코스 조회 실패는 장소 답변 자체를 실패시키지 않는다.
- 이미지가 없거나 로드되지 않아도 텍스트 카드가 유지된다.
- sessionStorage를 사용할 수 없어도 안내를 닫고 탐색할 수 있다.

## Verification

- 순수 URL/필터/노출 판정 로직은 Node 테스트로 보호한다.
- 타입체크, 린트, 프로덕션 빌드를 실행한다.
- localhost:3000에서 비로그인 안내, 챗봇 장소→내부 지도, 기존 코스 카드→코스 상세를 실제 화면으로 확인한다.
